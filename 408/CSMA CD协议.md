# 争用期
![](assets/CSMA%20CD协议/file-20260916210738509.png)
>极限情况 A结点发送数据经过30微秒要到达b节点前，b监听认为此时信道还是空的，于是发送数据，b结点发的数据又经过30微秒之后到达A结点，于是总共经过了60微秒，这是可以检测到冲突的最长时间，如果经过了60微秒，A结点都没检测到冲突，说明不会再冲突了，因为在30微秒的时候，A结点的数据已经充斥着整个信道，其他结点监听信道后不会发送数据
