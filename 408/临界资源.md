# 进程与[线程](线程.md) | 临界资源与同步

## 一、临界资源（Critical Resource）

**定义**：一次仅允许一个进程/线程访问的**共享资源**，用于防止**竞态条件**，确保数据一致性。

- **类型**：
    - 硬件：打印机、磁盘
    - 软件：共享变量、文件、队列
- **特点**：
    - 互斥访问（同一时刻仅一个进程/[线程](线程.md)使用）
    - 访问方式决定临界性（如文件读写 vs 只读）

## 二、临界区（Critical Section）

**定义**：进程中访问临界资源的**代码段**。
**结构**（四个部分）：

```markdown
进入区（Entry Section） → 临界区 → 退出区（Exit Section） → 剩余区
```

1. **进入区**：申请访问权（如 `P操作`/加锁）
2. **临界区**：操作临界资源
3. **退出区**：释放访问权（如 `V操作`/解锁）
4. **剩余区**：其他代码（与临界资源无关）

## 三、同步机制（进程/线程同步）

**目的**：确保临界资源互斥访问，避免竞态条件。
**常见方法**：

- **[信号](信号.md)量（Semaphore）**：`P/V操作`控制
- **互斥锁（Mutex）**：二元信号量，锁住/释放资源
- **条件变量（Condition Variable）**：线程间协作
- **管程（Monitor）**：封装资源与同步操作

## 四、进程 vs 线程 与 临界资源

| 进程 | 线程 |
| ------ |------ |
| 独立地址空间，资源隔离 | 共享进程地址空间 |
| 切换开销大 | 切换开销小 |
| 进程间需进程间通信（IPC） | 可直接共享临界资源（但需同步） |
| **注意**： |  |

- 多线程中，即使共享资源，仍需同步机制（如锁）保护临界区。
- 线程崩溃可能影响整个进程，进程崩溃不影响其他进程。

## 五、经典问题与案例

- **生产者-消费者问题**：
    - 临界资源：共享缓冲区
    - 同步：`empty`/`full` 信号量 + 互斥锁
- **读者-写者问题**：
    - 临界资源：共享数据
    - 优先读/写优先：通过读写锁或计数器实现

## 六、避免死锁

**死锁四大条件**：

1. 互斥
2. 占有并等待
3. 不可抢占
4. 循环等待
**预防/避免策略**：
- 资源分配策略（如按序分配）
- 银行家算法（避免）
