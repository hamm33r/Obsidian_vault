## 可分离变量型微分方程
1. 直接可分离
>把x放一边,y放等号另一边,两边积分
2. 换元后可分离
>形如$$\frac{dy}{dx}=f(ax+by+c)$$的方程
>直接令$u=ax+by+c$
>然后求$\frac{du}{dx}=a+b\frac{dy}{dx}$,再把原方程代入这个式子
>得到$\frac{du}{dx}=a+bf(u)$,然后分离变量两边积分

## 齐次型微分方程
### 形如$$\frac{dy}{dx}=\phi(\frac y x)$$的方程
直接令$u=\frac y x,y=ux,\frac{dy}{dx}=u+x\frac{du}{dx}$
原方程就变成了$u+x\frac{du}{dx}=\phi(x)$

## $y''=f(x,y')$型
>方程里不含着y,这时直接令$y'=p,p是x的函数$
>这样整个方程就没有y了,只有p和x
>求出p后,再把p写回y'

## $y''=f(y,y')$型
>方程里不含着x,要将x从方程中彻底换掉
>令$y'=p$此时p是y的函数,$y''=\frac{dp}{dy}\cdot \frac{dy}{dx}=p'(y)p(y)$
>求出p后将p写回$\frac{dy}{dx}$

## $y''=f(y')$型
>方程里不含y也不含x,用与$y''=f(x,y')$型一样的方法

### 小结
不显含x,将x斩草除根
不显含y,将y赶尽杀绝

# 微分方程解的结构
### 📝 一阶线性非齐次微分方程解的性质

#### 前提设定

设 $y_1, y_2, \cdots, y_n$ 都是一阶线性非齐次微分方程 $y' + p(x)y = q(x)$ 的**特解**。

#### 结论

对于线性组合 $y = k_1y_1 + k_2y_2 + \cdots + k_ny_n$，根据系数和 $\sum_{i=1}^n k_i$ 的不同，有如下性质：

- 当 $k_1 + k_2 + \cdots + k_n = 1$ 时： $k_1y_1 + k_2y_2 + \cdots + k_ny_n$ 仍是原非齐次方程 $y' + p(x)y = q(x)$ 的**特解**。
    
- 当 $k_1 + k_2 + \cdots + k_n = 0$ 时： $k_1y_1 + k_2y_2 + \cdots + k_ny_n$ 是对应齐次方程 $y' + p(x)y = 0$ 的**特解**。
    
- 当 $k_1 + k_2 + \cdots + k_n \neq 0$ 且 $\neq 1$ 时： $k_1y_1 + k_2y_2 + \cdots + k_ny_n$ **不再是解**。
