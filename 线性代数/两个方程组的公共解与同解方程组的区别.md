同解方程组与两个方程组的公共解**本质区别在于解集的覆盖范围**：同解要求**两个方程组的解集完全相同**，而公共解仅指**两个方程组解集的交集部分**。换言之，**同解是公共解的特殊情况**——当公共解恰好等于两个方程组各自的全部解时，二者才同解；但有公共解并不必然同解。

---

## 一、核心概念辨析

### 1. 公共解

- **定义**：同时满足两个方程组的所有方程的解，即**两个方程组解集合的交集**。
- **特点**：
    - 公共解可能有**唯一解、无穷多解或无解**。
    - **不要求**两个方程组的解集完全重合，只需存在部分共同解即可。
    

### 2. 同解方程组

- **特点**：
    
    - **同解必然有公共解，但有公共解不一定同解**。
    

---

## 二、关键区别总结

### 1. 解集关系

- **公共解**：仅关注解集的**交集部分**（可能为真子集）。
- **同解**：要求解集**完全相等**（无额外解或缺失解）。

### 2. 判定条件

#### （1）公共解的判定

- **只需联立方程组有解**：将两个方程组合并为新方程组 $\begin{pmatrix} A \ B \end{pmatrix}\mathbf{x} = \mathbf{0}$，若该方程组**有非零解**，则存在非零公共解。
- **无需验证双向包含性**。

#### （2）同解的判定

- **必须满足三秩相等**：$r(A) = r(B) = r\begin{pmatrix} A \ B \end{pmatrix}$。
- **或等价条件**：
    - 两个方程组的**行向量组等价**。
    - 一个方程组的解**全部是**另一个方程组的解，**且秩相等**（$r(A)=r(B)$）。
    - **必须双向验证**解集的互相包含性。

---

## 三、典型示例说明

### 例1：公共解但不同解

设方程组：

- (I) $\begin{cases} x_1 + x_2 = 0 \ x_1 - x_2 = 0 \end{cases}$，解为 $\mathbf{x} = \mathbf{0}$（唯一零解）。
    
- (II) $\begin{cases} 2x_1 + x_2 = 0 \ x_1 + 2x_2 = 0 \end{cases}$，解为 $\mathbf{x} = \mathbf{0}$（唯一零解）。
    
- **公共解**：存在唯一公共解 $\mathbf{x} = \mathbf{0}$。
    
- **是否同解**？
    
    - 虽然解相同，但需验证秩条件：$r(A)=2$，$r(B)=2$，$r\begin{pmatrix} A \ B \end{pmatrix}=2$，满足三秩相等，**实际同解**（此例特殊，因解集均为单点集）。

### 例2：有公共解但不同解

设方程组：

- (I) $\begin{cases} x_1 + x_2 = 0 \end{cases}$，解集为 ${ k(-1,1)^\top \mid k \in \mathbb{R} }$。
    
- (II) $\begin{cases} x_1 - x_2 = 0 \end{cases}$，解集为 ${ k(1,1)^\top \mid k \in \mathbb{R} }$。
    

- **是否同解**？
    
    - 解集明显不同（方向向量不共线），**不同解**。
    - 秩条件：$r(A)=1$，$r(B)=1$，但 $r\begin{pmatrix} A \ B \end{pmatrix}=2 \neq r(A)$，**不满足三秩相等**。

---

## 四、常见误区

### 1. 混淆“有公共解”与“同解”

- **错误观点**：若两个方程组有公共解，则它们同解。
- **正解**：有公共解仅说明解集有交集，但**同解要求解集完全重合**。例如，两个平面相交于一条直线（有无穷多公共解），但若直线不重合则不同解。

### 2. 误用秩条件

- **错误观点**：若 $r(A) = r(B)$，则两方程组同解。

---

## 五、总结

- **公共解**是两方程组**解集的交集**，只需存在共同解即可，**不要求解集完全一致**。
- **同解方程组**要求**解集严格相等**，必须满足**三秩相等**或**双向解集包含**。
- **关键判断**：若两个方程组同解，则它们必然有公共解；但**有公共解不保证同解**，需进一步验证解集是否完全重合。
