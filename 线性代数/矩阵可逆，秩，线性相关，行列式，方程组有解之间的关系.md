**核心关系（针对 $n \times n$ 方阵）**

以下所有条件**完全等价**，即满足其一必满足其余：

| 属性       | 等价条件                                        | 说明                                |
| -------- | ------------------------------------------- | --------------------------------- |
| **矩阵可逆** | $\iff$ 满秩（秩 $= n$）                          | 满秩意味着所有行/列向量“张成”整个 $n$ 维空间，存在逆矩阵。 |
|          | $\iff$ 行列式非零（$\det(A) \neq 0$）              | 行列式是体积缩放因子；非零表明变换不“坍缩”空间。         |
|          | $\iff$ 列向量线性无关                              | 线性无关的列向量构成 $n$ 维空间的一组基。           |
|          | $\iff$ 行向量线性无关                              | 行秩等于列秩，故行/列的线性无关性一致。              |
|          | $\iff$ 齐次方程 $A\mathbf{x} = \mathbf{0}$ 仅有零解 | 无非平凡解，表明变换是单射。                    |

**反之，以下条件也完全等价**：

|属性|等价条件|说明|
|---|---|---|
|**矩阵不可逆**|$\iff$ 不满秩（秩 $< n$）|秩亏缺，行/列向量无法张成完整空间。|
||$\iff$ 行列式为零（$\det(A) = 0$）|行列式为零表明变换“坍缩”了维度（如将 3D 压缩到 2D 平面）。|
||$\iff$ 列向量线性相关|存在冗余向量，可被其他向量线性表示。|
||$\iff$ 行向量线性相关|同上，行秩与列秩一致。|
||$\iff$ 齐次方程 $A\mathbf{x} = \mathbf{0}$ 有非零解|存在非平凡解，表明变换不是单射。|

#### 关键图示

```
方阵 A (n×n) 可逆
      ⇅
  det(A) ≠ 0
      ⇅
  秩(A) = n (满秩)
      ⇅
  列向量线性无关
      ⇅
  行向量线性无关
      ⇅
  A 非奇异
```

**所有箭头双向成立**，即上述任一条件成立，其余必然成立。

### 3. **非方阵的情况**

- **行列式与可逆性**：非方阵（$m \times n, m \neq n$）**没有行列式**，也**不可逆**（但可能有伪逆，如 Moore-Penrose 逆）。
- **满秩与线性相关**：
    - **列满秩**（秩 $= n$，要求 $m \geq n$）：列向量线性无关，但行向量可能线性相关（因行数 $m > n$）。
        - 例：$3 \times 2$ 矩阵若秩为 2，则两列线性无关，但三行必然线性相关（因行空间维度 $\leq 2 < 3$）。
    - **行满秩**（秩 $= m$，要求 $m \leq n$）：行向量线性无关，但列向量可能线性相关。
    - **不满秩**（秩 $< \min(m, n)$）：行向量和列向量均线性相关。
- **无直接等价关系**：非方阵中，满秩不蕴含可逆（因不可逆），也不涉及行列式。
